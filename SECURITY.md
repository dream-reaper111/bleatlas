# Security and privacy

Use only in an authorized environment. Passive advertisements can contain identifiers, names, and manufacturer data. Store the SQLite database and exports with appropriate local access controls; delete them when the assessment ends. Default retention is seven days and at most 100,000 observations. Imports reject oversized files and records. The dashboard is limited to loopback because it has no authentication. Do not publish it through a reverse proxy.

BLEAtlas performs no pairing, GATT connections, writes, RF transmission, address de-randomization, or person tracking. It does not estimate physical distance from RSSI. An address, company ID, or service UUID is an observation, not proof of ownership or a device's actual manufacturer. Report security issues through the repository owner.
